# arxiv-ocr

## プロジェクト概要

arxivの学術論文を「論文同士の手法の派生関係」「どのデータセットでどの手法が使 
  われ、どんな性能だったか」といった関係性の多段階推論が可能なRAGを構築する


## 使用モデル（テキスト読み取り）

テキスト読み取りモデルはQwenが軽量で精度が良いため採用（Hugging FaceのAPIで使用可）
ただし、MediumとHardで比較すると、Hardの落ち方が激しく要注意である
根拠論文：https://arxiv.org/pdf/2509.25922

 ## 4. プロジェクトの実装ステップ                                                                              
                                                                                                                
 #### Step 1: 環境準備                                                                                         
                                                                                                                
  • 使うツール:                                                                                                 
      • python3 -m venv / pip: Pythonの隔離された実行環境（.venv）を作り、ライブラリをインストールします。      
      • python-dotenv: Hugging Faceの無料アクセストークン（HF_TOKEN）を、ローカルの .env                        
      ファイルからPython内に安全に読み込むために使います。                                                      
                                                                                                                
  ──────                                                                                                        
  #### Step 2: 論文の取り込みスクリプト (ingest.py)                                                             
                                                                                                                
  論文PDFを読み込み、グラフDBに保存する処理です。4つのツールを組み合わせて使います。                            
                                                                                                                
  1. PyMuPDF (import fitz):                                                                                     
      • どこで: PDFを開いてテキスト化する部分。                                                                 
      • 何をする: arXivの論文PDFから本文テキストを丸ごと抜き出します（CPUで数秒、メモリ消費ほぼゼロ）。         
  2. pydantic:                                                                                                  
      • どこで: AIに渡す「出力フォーマットの型定義」の部分。                                                    
      • 何をする:                                                                                               
      「手法名（Method）」「派生元の親手法（derived_from）」「評価データセットとスコア（Evaluation）」というデー
      タ構造のルールをPythonコードで定義します。                                                                
  3. huggingface_hub (InferenceClient) + Qwen/Qwen2.5-72B-Instruct:                                             
      • どこで: 論文テキストから要点を抜き出すAI推論の部分。                                                    
      • 何をする: huggingface_hub 経由でクラウド上の Qwen2.5-72B にテキストを送信し、上記の pydantic            
      のルール通りに整ったJSONデータを出力させます。                                                            
  4. kuzu (KùzuDB):                                                                                             
      • どこで: 取り出したデータを保存する部分。                                                                
      • 何をする:                                                                                               
      手元のPC内にグラフDBファイルを作成し、Qwenが抽出したJSONを使って「ノード（点：手法名）」と「リレーション（
      矢印：派生関係やスコア）」を書き込みます。                                                                
                                                                                                                
  ──────                                                                                                        
  #### Step 3: 質問回答スクリプト (query.py)                                                                    
                                                                                                                
  「ResNetから派生した手法と、その性能を教えて」といった質問に答える処理です。2つのツールを使います。           
                                                                                                                
  1. kuzu (KùzuDB):                                                                                             
      • どこで: 質問に関連するデータをDBから探す部分。                                                          
      • 何をする: 質問に含まれる単語（例:                                                                       
      ResNet）をもとに、Cypherクエリで「ResNetから伸びている派生矢印と、その先の手法・スコア」のつながり（サブグ
      ラフ）を取り出します。                                                                                    
  2. huggingface_hub + Qwen/Qwen2.5-72B-Instruct:                                                               
      • どこで: ユーザー向けの最終的な回答文を作る部分。                                                        
      • 何をする: KùzuDBから取り出した「つながりのデータ」をQwen2.                                              
      5に渡し、「このデータをもとに、ユーザーの質問にわかりやすく日本語で答えて」と指示して、回答を出力させます 
      。                                                                                                        
                                                                                                                
  ──────                                                                                                        
  #### Step 4: グラフ可視化スクリプト (visualize.py)                                                            
                                                                                                                
  DBにどんな家系図ができあがったかを人間が目で見て確認する処理です。                                            
                                                                                                                
  1. kuzu (KùzuDB):                                                                                             
      • 保存されているすべての手法ノードと派生リレーションを全件取得します。                                    
  2. pyvis:                                                                                                     
      • 取り出したノードと矢印を、ブラウザ上でマウスドラッグして動かせるインタラクティブなHTML図（graph.        
      html）に変換して保存します。
